# CodeAlpha FAQ Chatbot

## Project Overview

This project is an AI-powered FAQ Chatbot developed as part of the CodeAlpha Artificial Intelligence Internship.

The chatbot answers user questions by finding the most similar question from a predefined FAQ dataset using Natural Language Processing (NLP) techniques.

## Features

* FAQ-based question answering
* NLP text processing
* TF-IDF Vectorization
* Cosine Similarity Matching
* Interactive chatbot conversation

## Technologies Used

* Python
* Scikit-Learn
* NumPy

## How It Works

1. Store FAQs and answers.
2. Convert questions into TF-IDF vectors.
3. Convert user query into vector form.
4. Calculate cosine similarity.
5. Return the most relevant answer.
